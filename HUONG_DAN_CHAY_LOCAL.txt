================================================================================
          HƯỚNG DẪN CHẠY DỰ ÁN IOT GREENHOUSE TRÊN MÁY TÍNH LOCAL
================================================================================

1. KIẾN TRÚC TỔNG THỂ
--------------------------------------------------------------------------------
Node 1 (luôn bật) ──┐
                    ├── MQTT/1883
Node 2 (ngủ sâu) ───┘
   │ topics sh/home1/{device_id}/telemetry
   ▼
Mosquitto Broker (Port 1883)
   │ (Backend subscribe topic mới và topic greenhouse cũ)
   ▼
Backend Spring Boot (Port 8080) ──▶ PostgreSQL Database (Port 5432)
   │ (REST API)
   ▼
Frontend React / Vite (Port 5173 - Web Dashboard)


2. THÔNG TIN CẤU HÌNH MẶC ĐỊNH
--------------------------------------------------------------------------------
- PostgreSQL:
    Host: localhost (127.0.0.1) | Port: 5432
    Database Name: iot_greenhouse
    Username: postgres
    Password: postgres

- MQTT Broker (Mosquitto - cấu hình local/dev):
    Host LAN: địa chỉ LAN của máy chạy Mosquitto | Port: 1883
    Topic Telemetry mới: sh/home1/{device_id}/telemetry
    Topic Telemetry tương thích ngược: greenhouse/{device_id}/telemetry
    Firmware hiện chỉ nhận lệnh qua topic sh/home1/{device_id}/cmd hoặc
    greenhouse/{device_id}/control; backend chưa phát lệnh MQTT.

- Tài khoản đăng nhập Web:
    Tài khoản quản trị chỉ được tạo lần đầu nếu đã đặt BOOTSTRAP_ADMIN_PASSWORD.
    Không dùng mật khẩu mặc định; tự chọn mật khẩu riêng trước khi chạy backend.


3. CÁC BƯỚC KHỞI CHẠY HỆ THỐNG MỖI KHI BẬT MÁY
--------------------------------------------------------------------------------

[BƯỚC 1]: Kiểm tra Dịch vụ Nền (PostgreSQL & Mosquitto)
Dịch vụ PostgreSQL và Mosquitto đã được cài đặt dưới dạng Windows Service,
thông thường sẽ tự động chạy ngầm khi bật máy.
Nếu cần khởi động lại thủ công, mở PowerShell (quyền Admin) chạy:
    Start-Service postgresql-x64-16
    Start-Service mosquitto


[BƯỚC 2]: Chạy Backend Spring Boot
Mở cửa sổ PowerShell số 1:
    cd c:\Users\Admin\Desktop\IOT_GreenHouse\backend
    $env:DB_URL="jdbc:postgresql://localhost:5432/iot_greenhouse"
    $env:DB_USERNAME="postgres"
    $env:DB_PASSWORD="postgres"
    $env:BOOTSTRAP_ADMIN_USERNAME="admin"
    $env:BOOTSTRAP_ADMIN_EMAIL="admin@greenhouse.local"
    $securePassword = Read-Host "Nhập mật khẩu quản trị" -AsSecureString
    $env:BOOTSTRAP_ADMIN_PASSWORD = [System.Net.NetworkCredential]::new("", $securePassword).Password
    $env:MQTT_ENABLED="true"
    $env:MQTT_BROKER_URL="tcp://localhost:1883"
    .\mvnw.cmd spring-boot:run

Chờ khoảng 10-15 giây đến khi thấy dòng: "Started GreenhouseApplication".


[BƯỚC 3]: Chạy Frontend (Web Dashboard)
Mở cửa sổ PowerShell số 2:
    cd c:\Users\Admin\Desktop\IOT_GreenHouse\frontend
    npm run dev

Mở trình duyệt truy cập: http://localhost:5173 và đăng nhập bằng tài khoản/mật khẩu
đã cấu hình qua BOOTSTRAP_ADMIN_USERNAME và BOOTSTRAP_ADMIN_PASSWORD.


4. CẤU HÌNH VÀ KẾT NỐI ESP32 VỚI SERVER
--------------------------------------------------------------------------------
1. Phân bổ phần cứng theo thiết kế hai node:
   - Node 1 (nguồn ổn định): DHT22 GPIO 27, relay quạt GPIO 33, relay đèn GPIO 32.
   - Node 2 (pin): DHT22 GPIO 27, relay van GPIO 25. Cảm biến đất điện dung
     tại GPIO 35 là phần mở rộng, firmware mặc định chưa bật.
   - Mỗi node dùng ESP32 riêng. Không nối relay của cả ba tải vào một node.
   - Tải quạt/đèn/van dùng nguồn DC riêng. Dùng chung GND theo thiết kế mạch;
     van DC cần diode flyback. Không dùng điện lưới.

2. Nạp code:
   - Mở file: firmware\esp32_telemetry\esp32_telemetry.ino trong Arduino IDE.
   - Thư viện cần có: WiFiManager, PubSubClient, DHT sensor library.
   - Chọn Board "ESP32 Dev Module", chọn cổng COM và bấm Upload.

3. Kết nối Wi-Fi qua Web Portal:
   - Khi bật nguồn lần đầu, ESP32 phát Wi-Fi tên "GreenHouse_ESP32_Setup";
     mật khẩu ngẫu nhiên được in trong Serial Monitor ở 115200 baud.
   - Lấy điện thoại/laptop kết nối vào Wi-Fi đó -> Trang web tự bật (hoặc gõ 192.168.4.1).
   - Bấm "Configure WiFi" -> Chọn Wi-Fi nhà bạn và gõ mật khẩu.
   - Chọn vai trò `node1` hoặc `node2`, nhập IP broker, port 1883, device_id duy
     nhất đã đăng ký và zone tương ứng. Node 1 mặc định là `esp32-n1/livingroom`,
     Node 2 là `esp32-n2/balcony` khi cấu hình mới.
   - Bấm Save. Node 1 giữ kết nối; Node 2 gửi telemetry rồi ngủ sâu 15 phút.
     Firmware đồng bộ NTP và gửi `device_id/ts/seq/zone/q/fw`; nếu chưa có giờ
     NTP, bản tin không được gửi.
   - Quạt Node 1 dùng hysteresis 30/28 °C. Van Node 2 tự đóng sau tối đa 30
     giây; phải xác nhận lưu lượng trước khi nối van thật.

   * Mẹo đổi Wi-Fi: Bấm giữ nút BOOT trên ESP32 trong 3 giây để xóa cấu hình và phát lại Wi-Fi Setup.


5. CÂU LỆNH TEST KÍCH RELAY TỪ XA QUA POWERSHELL
--------------------------------------------------------------------------------
Mở PowerShell mới và chạy các lệnh sau để test nhảy relay (kêu cạch & sáng đèn LED):

- Bật Van nước (IN1):
& "C:\Program Files\mosquitto\mosquitto_pub.exe" -h localhost -p 1883 -t "greenhouse/esp32-01/control" -m '{"valve":1}'

- Tắt Van nước (IN1):
& "C:\Program Files\mosquitto\mosquitto_pub.exe" -h localhost -p 1883 -t "greenhouse/esp32-01/control" -m '{"valve":0}'

- Bật Quạt (IN2):
& "C:\Program Files\mosquitto\mosquitto_pub.exe" -h localhost -p 1883 -t "greenhouse/esp32-01/control" -m '{"fan":1}'

- Tắt Quạt (IN2):
& "C:\Program Files\mosquitto\mosquitto_pub.exe" -h localhost -p 1883 -t "greenhouse/esp32-01/control" -m '{"fan":0}'

- Bật Đèn (IN3):
& "C:\Program Files\mosquitto\mosquitto_pub.exe" -h localhost -p 1883 -t "greenhouse/esp32-01/control" -m '{"light":1}'

- Tắt Đèn (IN3):
& "C:\Program Files\mosquitto\mosquitto_pub.exe" -h localhost -p 1883 -t "greenhouse/esp32-01/control" -m '{"light":0}'
