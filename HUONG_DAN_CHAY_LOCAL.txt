4. CẤU HÌNH VÀ KẾT NỐI ESP32 VỚI SERVER
--------------------------------------------------------------------------------
1. Sơ đồ nối dây (Đã chốt):
   - Nguồn:
       ESP32 cắm cáp USB máy tính
       VIN (5V) ESP32 -> DC+ Relay (chân ngoài cùng bên phải)
       GND ESP32      -> Rail Xanh (Breadboard GND)
       3V3 ESP32      -> Rail Đỏ (Breadboard 3.3V)
       DC- Relay      -> Rail Xanh (GND chung)
   - Cảm biến:
       DHT22 : OUT -> D27  |  + -> Rail Đỏ (3.3V)  |  - -> Rail Xanh (GND)
       HW-390: AOUT -> D35 |  VCC -> Rail Đỏ (3.3V)|  GND -> Rail Xanh (GND)
   - Relay 4 kênh (Active LOW):
       D25 -> IN1 (Van nước)
       D33 -> IN2 (Quạt gió)
       D32 -> IN3 (Đèn quang hợp)
       IN4: Bỏ trống

2. Nạp code:
   - Mở file: firmware\esp32_telemetry\esp32_telemetry.ino trong Arduino IDE.
   - Thư viện cần có: WiFiManager, PubSubClient, DHT sensor library.
   - Chọn Board "ESP32 Dev Module", chọn cổng COM và bấm Upload.

3. Kết nối Wi-Fi qua Web Portal:
   - Khi bật nguồn lần đầu, ESP32 phát Wi-Fi tên: "GreenHouse_ESP32_Setup" (Pass: 12345678).
   - Lấy điện thoại/laptop kết nối vào Wi-Fi đó -> Trang web tự bật (hoặc gõ 192.168.4.1).
   - Bấm "Configure WiFi" -> Chọn Wi-Fi nhà bạn và gõ mật khẩu.
   - Các thông số IP Server (192.168.1.220), Cổng (1883), Device ID (esp32-01) đã điền sẵn.
   - Bấm Save. ESP32 sẽ tự nhớ vào Flash và gửi dữ liệu về Dashboard mỗi 10 giây!

   * Mẹo đổi Wi-Fi: Bấm giữ nút BOOT trên ESP32 trong 3 giây để xóa cấu hình và phát lại Wi-Fi Setup.
